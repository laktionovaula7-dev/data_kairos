# KRS / Кайрос — дашборд продаж (актуальная версия)

Живой веб-дашборд (один HTML) по продажам ООО «Кайрос».
Данные считаются из Excel скриптом. Работает фильтр по периоду (месяц / произвольный
диапазон) — пересчитывает Обзор и карточки клиентов вплоть до SKU.

## Файлы
| Файл | Что это |
|------|---------|
| `KRS_real_data.html` | Готовый дашборд. Открывается двойным кликом. |
| `KRS_template.html`  | Шаблон (вёрстка + слот данных). Скрипт вставляет в него данные. |
| `build_data.py`      | Скрипт: Excel → данные → пересборка дашборда. |
| `krs_data.json`      | Посчитанные данные (результат скрипта). |
| `data/`              | Исходные Excel (уже внутри). |

> `KRS_real_data.html` и `KRS_template.html` сейчас одинаковы. Правки ВЁРСТКИ вносите
> в `KRS_template.html`, а `KRS_real_data.html` пусть пересобирается скриптом —
> тогда данные и дизайн не конфликтуют.

## Обновление данных (новая выгрузка из 1С)
1. Положить свежие файлы в `data/` (имена — как в начале `build_data.py`):
   `Продажи_по_Бизнес_Регионам.xlsx`, `Инструмент_клиенты_категории_А_по_АВС.xlsx`, `Прайс.xlsx`
2. Запустить:  `pip install openpyxl` (один раз), затем `python build_data.py`
3. Обновится `KRS_real_data.html` — открыть в браузере.

Дата «сегодня» для «дней без заказа» — константа `REF_DATE` вверху скрипта.

## Что считается (есть в Excel)
Продажи/возвраты/итог, заказы, средний чек; все 161 клиент и 14 менеджеров;
помесячная динамика; ABC (доли выручки A/B/C, локомотивы, резерв допродаж);
матрица категорий и проникновение; резерв A-позиций; история заказов;
ТРАНЗАКЦИИ с датами до SKU (для фильтра периода); остатки склада
(в наличии/резерв/доступно/поступит) и дефицит; заказы в работе (не отгружено).

## Что «нужен источник» (нет в Excel)
План и выполнение плана; Δ к прошлому году (АППГ/2025); скидки; маржинальность;
продажи KRONbuild и ENKI; филиал Владивосток; сроки годности; логистика доставки.
В данных = null → в дашборде помечено «нужен источник».

## Главное ограничение
Сверка товар↔прайс идёт по НАЗВАНИЮ (~63% точного матча) — в выгрузке продаж
у товара нет артикула, только название, а написания местами расходятся.
**Артикул в выгрузке продаж поднимет сверку до 100%** — приоритетный запрос к 1С.

## Как устроены данные (для правок)
Дашборд читает один объект `window.KRS_DATA`. Ключи:
overview, abcSummary, abcDetail, clients[], clientDetail{}, managersFull,
stock, lowStock, ordersInWork, tx/txClients/txCats/txSkus (транзакции для периода),
catTotal (знаменатель проникновения).
Фильтр периода: функции `periodRange()`, `recompute()` (Обзор), `clientByPeriod()` (клиент).
