# ТЗ: вкладка «Продажи»

Статус: описывает реализованное поведение прототипа (`Kairos_dashboard_proto.html`; вёрстка — `Kairos_proto_template.html`, данные подставляет `rebuild.py`). Раздел 11 — открытые вопросы. Дополняет `sales-page-spec.md` (исходная концепция); при расхождении актуален этот документ.

## 1. Назначение

Вкладка отвечает на вопрос «как мы продаём в выбранном срезе компании»: сколько, чего, где, кому, как это соотносится с планом, прошлым годом и всей компанией. Срез может быть любым: вся компания, филиал (Москва / Владивосток / Сети), один или несколько регионов (округов), город, бренд, менеджер, клиент, категория, товар и их сочетания. Москва — лишь один из примеров.

Аудитория: руководство и собственник (статус за 3 секунды), коммерческий директор / РОП (контроль и проваливание), аналитик (разрезы, выгрузки), планёрка (большой экран, читаемость издалека).

## 2. Структура вкладки

Две подвкладки с общими фильтрами и общим срезом:
1. **Результаты продаж** — продажи, план, динамика, география и покрытие, категории и товары, компании, разбивка.
2. **Ассортимент и ABC** — что срез берёт и не берёт относительно ассортимента компании, менеджеры среза, выгрузка в Excel.

Переключение подвкладок сохраняет срез и период. Кнопка «Назад» (и Alt+←) возвращает к предыдущему состоянию (стек навигации).

## 3. Общие фильтры и срез

### 3.1 Состав
- **Период** (всегда на виду): «Весь 2026 / 2025 / 2024», отдельный месяц любого года, «Произвольный…». По умолчанию текущий год до последнего месяца с данными (YTD).
- **Панель «Фильтры»** (кнопка со счётчиком выбранного): Филиал, Регион, Город, Менеджер, Бренд (HeadRock / KRONbuild / ENKI), Категория, Товар (поиск), Клиент (поиск). Все мультивыбор.
- **Дополнительно** — локальные фильтры списков, не меняющие KPI среза: сумма продаж в разбивке (больше/меньше N млн ₽), «охват территории ниже X%», «клиенты покупают меньше X% позиций».
- Метки выбранного с крестиком и «Сбросить всё»; при пустом срезе — «Срез: вся компания · весь период».

### 3.2 Правила
1. Все фильтры действуют совместно, порядок выбора любой.
2. Каскад: список регионов зависит от выбранных филиалов, города — от филиалов и регионов, менеджеры и клиенты — от всех выбранных выше. Несовместимые дочерние выборы при смене родителя сбрасываются.
3. «Сети» — канал без регионов: при выборе только «Сети» поле «Регион» недоступно, городские блоки заменяются пометкой «федеральный канал».
4. Клик по региону на карте, по строке района в списке, по бренду/филиалу на «Обзоре» добавляет это значение в фильтр (переходы с «Обзора» открывают «Продажи» с готовым срезом и нужной разбивкой).
5. «Сбросить» очищает срез, период сохраняется.
6. Уровень среза для заголовков: клиент → менеджер → город → регион → филиал → вся компания (берётся самый детальный выбранный).

### 3.3 Определение филиала
Клиент относится к «Сети», если его канал в 1С = СЕТИ; иначе к «Владивосток», если филиал Владивосток; иначе к «Москва». Регион клиента — по CRM-справочнику, дозаполняется из выгрузок «Регионы/».

## 4. Подвкладка «Результаты продаж»

Порядок блоков сверху вниз. Все блоки считаются по одному срезу и периоду. Сравнение везде — с аналогичным периодом прошлого года (АППГ).

### 4.1 Верхняя полоса
- **Продажи** (нетто) и Δ к АППГ.
- **Выполнение плана** — см. раздел 6; когда план неприменим, показывается «—» с причиной.
- Метрики с Δ к АППГ: клиенты, заказы, средний чек, продано шт., число SKU.

### 4.2 Динамика
- «Продажи» по месяцам года периода: факт (столбец) и план (при применимом плане), подпись суммы над столбцом; при наведении — месяц, факт, план, % выполнения, Δ к АППГ.
- «По брендам»: линии KRON+ENKI и HeadRock (факт — сплошная, план — пунктир). Если выбран один бренд, блок брендов скрывается.

### 4.3 Регионы и покрытие (карта)
- Карта РФ по округам; закрашены округа, входящие в срез, остальные — серые. Цвет заливки — сила продаж территории (зелёный — сильно, жёлтый — средне, красный — слабо), круги — размер продаж, выбранный округ обводится. Зум колесом/кнопками, всплывающие подсказки (продажи, доля, покрыто городов).
- Без выбора — рядом со картой список округов (ABC территории, продажи, доля, флаг «зона роста», раскрывается до субъектов и городов); при выборе региона/города/филиала карта на всю ширину.
- Сводка: покрыто субъектов и крупных городов; строка «где слабо продаём».

### 4.4 Панель среза (под картой, показывается всегда)
1. **Герой «Покрытие городов»** (тёмный): доля крупных городов территорий среза, где есть продажи; вердикт словами (≥60% уверенное / 30–59% есть куда расти / <30% слабое); доля среза в продажах компании; число компаний с Δ к АППГ; доля A-позиций компании, которые берёт срез; число просевших городов; кнопка «ABC-анализ среза» → подвкладка ABC с тем же срезом.
2. **Где продаём**: города с продажами (по убыванию, лидер выделен); **Не продаём** — чипы городов без продаж; **Просели** — города с продажами ниже АППГ более чем на 20% и процент падения.
3. **Покрытие по брендам**: по каждому бренду продажи, доля, число городов и компаний; при выборе одного бренда — только он.
4. **ABC среза**: по классам A/B/C доля позиций компании, которые берёт срез; число компаний класса и доля выручки; перечень A-позиций, которые срез не берёт.
5. **Категории и топ-10 товаров**: полукруг долей категорий и 10 лучших товаров среза.
6. **Компании среза**: топ-10 по выручке (ABC внутри среза, Δ к АППГ, «новая»), счётчик новых; **Потеряли компаний** — покупали в АППГ, в периоде нет (счётчик, сумма, топ-10).
7. Ведущий менеджер среза.

### 4.5 Разбивка продаж
Таблица продаж среза в выбранном измерении: Регионы / Города / Клиенты / Товары / Бренды / Менеджеры (измерение, совпадающее с единственным выбранным значением фильтра, скрывается). Колонки: название, ABC внутри среза (A≤80%, B≤95%, C), продажи, доля. Сортировка по выручке, показано до 30 строк, счётчик «показано N из M». Клик по клиенту — карточка клиента.

## 5. Подвкладка «Ассортимент и ABC»

- **База сравнения** — ассортимент всей компании за период (эталон ABC), без фильтров географии и менеджеров.
- **Сводка ABC берёт / не берёт**: по A/B/C и итого — всего позиций, берёт, доля, не берёт, % и «не берёт, но есть в наличии».
- **Матрица ABC**: класс позиции у компании × класс у среза / «не берёт».
- **Не берёт — список**: группа, артикул, номенклатура, ABC, продажи по компании, проникновение (% клиентов компании, берущих позицию), потенциал на клиента, статус (отвал — брал в прошлом году; никогда), остаток.
- **Склад**: выбор склада для остатков — все склады или конкретный (Лакония ОПТ / СЕТИ / прочее, Владивосток, Москва, Новосибирск, Прочее).
- **Менеджеры среза**: список с ABC менеджера, регионами, числом активных компаний из закреплённых, брендами; раскрытие — компании менеджера (ABC, доля), «выбрать менеджера» добавляет его в срез; при выбранном менеджере — таблица покрытия A-позиций по его клиентам.
- **Выгрузка в Excel** (кнопка «Выгрузить»): сводка, матрица и список «не берёт» с учётом среза, склада и бренда; шапка файла содержит срез, период, склад.

## 6. План

- Источник — `План_25_26.xlsx`: помесячно по каналам «ОПТ Москва», «ОПТ Владивосток», «Сети» × группам брендов «KRONbuild+ENKI», «HeadRock».
- План среза = сумма по выбранным филиалам и брендам за месяцы с начала периода до последнего месяца с данными. Выполнение = факт / план YTD; «До плана» = остаток, при перевыполнении — «Перевыполнение».
- План не показывается, если выбран регион, город, менеджер, клиент, категория, товар или один из KRONbuild/ENKI без второго (в плане они вместе). В блоке выводится причина.
- Контроль: для «вся компания» план YTD равен значению на «Обзоре».

## 7. Расчёты

| Показатель | Правило |
|---|---|
| Продажи | нетто (за вычетом возвратов); служебные и нулевые клиенты исключены |
| Δ к АППГ | период этого года vs те же месяцы прошлого года (до последнего месяца с данными) |
| Заказы | уникальные пары «клиент + дата» |
| Средний чек | продажи / заказы |
| ABC (позиции, клиенты, регионы, менеджеры) | сортировка по выручке по убыванию, накопленная доля: A ≤80%, B ≤95%, C >95% |
| Покрытие городов | города справочника территорий среза с продажами / все города территорий среза |
| Просели | продажи города < 80% продаж АППГ (при продажах АППГ > 0) |
| Потеряли | продажи в АППГ > 0 и нет продаж в периоде |
| Покрытие A-позиций | A-позиции компании, которые есть в продажах среза / все A-позиции компании |

Источники: «Продажи по бизнес регионам 24г-26г.xlsx», «План_25_26.xlsx», «Остатки и доступность по сериям.xlsx», справочник территорий, CRM-выгрузки «Регионы/», «Справочник_клиентов.xlsx». Подробнее — `МЕТОДИКА_РАСЧЕТОВ.md`.

## 8. Состояния и граничные случаи

- Пустой срез: «нет данных под фильтры», без ошибок и без деления на ноль.
- «Сети»: нет городских блоков и плана по регионам; план по каналу «Сети» показывается.
- Срез из одного бренда/менеджера/клиента: соответствующее измерение разбивки скрыто.
- Нет данных за последние месяцы периода: расчёты ограничены последним месяцем с данными.
- Конфиденциальность: файл содержит реальные данные компаний, хранится в приватном репозитории.

## 9. Визуальные требования

- Опора — вкладка «Обзор», `Дизайн/РЕФЕРЕНСЫ.docx`, брендбук «Кайрос 2026» (выжимка в `PRODUCT.md`): графит `#2A2A2A`, белый, тёплый серый; красный `#C7001F` — только внимание и негатив; жёлтый `#FDCF08` — поддержка и главные кнопки; шрифты Unbounded (заголовки, цифры) и Montserrat (текст).
- Тёмные карточки с красно-жёлтым свечением для главного вывода, белые карточки с радиусом 20–22 px, градиентные полосы «жёлтый → красный», подъём карточки при наведении.
- Разные формы данных (столбцы, линии, полосы, полукруг, таблица); зелёный/красный только как статус.
- Адаптив: до 1000 px блоки в одну колонку; крупные числа для большого экрана.
- Открывается двойным кликом офлайн; внешние шрифты с системным фолбэком.

## 10. Критерии приёмки

1. Без фильтров вкладка показывает всю компанию; план YTD равен «Обзору».
2. Каждый сценарий — вся компания; Москва; Владивосток; Сети; один округ кликом по карте; два округа из фильтра; бренд HeadRock; менеджер; клиент — открывается без ошибок JS, все блоки пересчитываются по одному срезу.
3. Выбор региона кликом по карте, через фильтр и через список даёт одинаковый срез.
4. План: показывается для филиала и бренда, не показывается для региона/города/менеджера/клиента с пояснением.
5. Сумма «Где продаём» не превышает продажи среза; города из «Не продаём» не имеют продаж в срезе.
6. Переход с «Обзора» (бренд, филиал, менеджеры) открывает нужный срез и разбивку; «Назад» возвращает.
7. Кнопка «ABC-анализ среза» открывает подвкладку ABC с тем же срезом; Excel-выгрузка содержит срез, период и склад.
8. Каскад фильтров не оставляет несовместимых выборов.
9. Нет данных о марже, себестоимости, скидках — они не выдумываются; предварительные показатели помечены.

## 11. Открытые вопросы

- Часть городов (например, Москва) попадает в «Не продаём», хотя продажи есть: они учтены по региону, а не по городу. Нужно решение по привязке.
- Порог «просели» (−20%), состав «крупных городов» и пороги вердикта покрытия (30/60%) — подтвердить.
- ABC компаний: считать внутри среза (сейчас) или относительно всей компании.
- Нужен ли план с детализацией по региону / менеджеру (в источнике его нет).
- Категории в стиле ленты-«воронки» из референсов не реализованы; сейчас полукруг.
- Подвкладка «Ассортимент и ABC» не приведена к стилю «Обзора» (панель среза приведена).
